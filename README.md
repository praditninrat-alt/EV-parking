# EV Park สำหรับบริษัท

ระบบภาษาไทยสำหรับดูตารางและจองเวลาหัวชาร์จ EV จุดเดียว ใช้ SQLite เป็นไฟล์ในเครื่องโดยไม่ต้องติดตั้งฐานข้อมูล server แยก การจองตรวจช่วงเวลาซ้ำและไม่มีค่าบริการ

## ตั้งค่าระบบ

ต้องใช้ Node.js 20.9 หรือใหม่กว่า คัดลอก `.env.example` เป็น `.env` แล้วตั้งค่า `ADMIN_PASSWORD` เป็นรหัสผ่านผู้ดูแลที่ต้องการ และแก้ข้อมูลจุดชาร์จตามจริงได้:

```powershell
Copy-Item .env.example .env
npm install
npm run db:generate
npm run db:setup
npm run dev
```

เข้าสู่ระบบด้วยรหัสพนักงาน `ADMIN` และรหัสผ่านจาก `ADMIN_PASSWORD` ไฟล์ `.env` ถูกกันไม่ให้ commit แล้ว อย่าเผยแพร่ไฟล์นี้หรือใช้รหัสผ่านตัวอย่างในระบบจริง

## การจองและข้อจำกัด

- รายการจองเก็บใน SQLite ที่ `backend/prisma/ev-parking.db` จึงยังอยู่หลังเซิร์ฟเวอร์รีสตาร์ต
- ต้องรันโปรแกรมบนเครื่องหรือบริการที่เก็บไฟล์ไว้ถาวร หาก deploy บนบริการที่ลบไฟล์ระบบเมื่อเริ่มใหม่ ต้องตั้ง persistent volume ให้โฟลเดอร์นี้
- ระบบนี้ออกแบบให้รัน Node.js process เดียว ไม่เหมาะกับ serverless หรือหลาย instance ที่ไม่ได้ใช้ไฟล์ฐานข้อมูลร่วมกัน
- เปิดให้จองทุกวันเวลา 08:00–18:00 ตามเวลาไทย รายการที่หมดเวลาแล้วจะไม่แสดงในตาราง
- รหัสผ่าน Admin อยู่ใน environment variable จึงมี Admin บัญชีเดียวสำหรับผู้ใช้ทั้งหมด
- หน้าเว็บตรวจรายการจองทุก 30 วินาทีและแจ้งเตือนก่อนถึงเวลา 10 นาทีแก่ผู้ใช้ที่ Login และเปิดหน้าเว็บไว้ ข้อความไม่แสดงรหัสพนักงาน; กด “เปิดแจ้งเตือน” เพื่ออนุญาต browser notification หรืออ่านข้อความเตือนในหน้าเว็บ
- หน้าเว็บตรวจรายการจองทุก 30 วินาทีและแจ้งเตือนก่อนถึงเวลา 10 นาทีแก่ผู้ใช้ที่ Login และเปิดหน้าเว็บไว้ ข้อความไม่แสดงรหัสพนักงาน; กด “เปิดแจ้งเตือน” เพื่ออนุญาต browser notification หรืออ่านข้อความเตือนในหน้าเว็บ

> สำรองไฟล์ `backend/prisma/ev-parking.db` เป็นระยะ เพื่อป้องกันข้อมูลสูญหายจากความเสียหายของดิสก์

## API

หน้าเว็บใช้ API สำหรับ Login (`/api/auth/login`, `/api/auth/logout`, `/api/auth/me`), จุดชาร์จ (`/api/org/charging-point`) และตารางจอง (`/api/org/bookings`) โดยทุก response ใช้ `{ data: ... }` เมื่อสำเร็จ และ `{ error: { code, message } }` เมื่อเกิดข้อผิดพลาด การยกเลิกการจองใช้ `POST /api/org/bookings/:id/cancel`

เวลาเปิดบริการและตรวจสอบเวลาจองอิง `Asia/Bangkok` การจองของบริษัทได้รับการยืนยันโดยตรงและคิดราคา 0 บาท
